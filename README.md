# Privacy Policy for Asmart

**Effective Date:** October 16, 2026

Asmart ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how your information is collected, used, and safeguarded when you use the Asmart mobile application.

### 1. Information Collection and Use
Asmart is an agricultural and sales management application. We collect minimal operational data necessary to provide and support application services, including:
- Local sales records, inventory data, and client transaction details.
- User profile details managed directly by the account owner.

### 2. Data Storage and Security
- Local data is stored securely on your device using encrypted/offline databases.
- Synchronized data is securely stored using Supabase infrastructure with standard encryption standards.

### 3. Third-Party Services
Asmart uses trusted services such as Supabase for database synchronization. We do not sell or trade your personal data to third parties.
